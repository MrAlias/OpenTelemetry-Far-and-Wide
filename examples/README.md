# Code examples

Use this directory for small examples that explain one instrumentation concept
at a time. Examples should be independently runnable and should not depend on
the full live-demo environment.

Organize examples around:

- eBPF-only instrumentation;
- SDK auto-injection by language;
- combined eBPF and SDK telemetry;
- SDK version selection or upgrade; and
- dynamic telemetry cost and detail controls.

Each example should include its own README with prerequisites, commands,
expected telemetry, and cleanup instructions.
