# Attendee resources

Use this directory for the curated follow-up material shared with attendees:

- links to relevant OpenTelemetry specifications and projects;
- architecture diagrams and downloadable handouts;
- demo and example navigation;
- cost-control guidance; and
- troubleshooting or adoption checklists.

For external material, record a descriptive title, canonical URL, access date,
and the claim or slide it supports. Do not commit third-party assets unless
their license permits redistribution.
